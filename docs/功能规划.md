# CodeKit 功能候选清单

> 规划日期：2026-10-04  
> 定位：通用开发工具箱。本文记录候选功能及已落地的开发批次。

建议优先补充**高频、离线、输入即出结果**的功能，兼顾前后端日常开发需求。

## 当前基础

已具备 JSON、时间戳、Base64/哈希/AES/RSA、ID/密码生成、文本 Diff、正则测试、命名转换、二维码工具，共 8 个工具页面。统一注册和路由机制方便新增工具，Monaco 编辑器也可以复用。

## 已实现：二维码生成与导出

- 独立「二维码工具」页面，接入侧栏、工具搜索和最近使用，归属研发生成器。
- 输入文本或完整链接后，停顿 300ms 自动生成；保留中文、emoji、空格与换行，支持清空及导出 `qrcode.png`。
- 标准二维码采用 UTF-8、M 级纠错、四个模块白色留边与不透明黑白图案，PNG 边长至少 512px，按整数像素绘制；深色主题保持黑码白底。
- 全部本地处理；空输入与超容量内容显示提示，内容不截断。切换工具保留当前内容，不增加重启恢复。
- 自动测试使用独立解码器核对生成 PNG 的内容，并覆盖防抖、过期结果、错误恢复与清空操作。手机微信屏幕扫码及相册识别仍需实机验收；网址能否打开取决于可达性及微信策略。
- 本地二维码图片识别仍为后续候选。

代码与 README 有些出入：文档列出的 URL、Unicode、Hex 转换，在当前编解码页面中没有入口；“文本处理”目前主要是 Diff。这两处适合优先补齐。

## 优先推荐的功能

工作量为基于现有代码的相对估计，包含基本界面和验证。

| 候选功能 | 建议内容 | 使用价值 | 工作量 |
| --- | --- | --- | --- |
| **URL 解析与编解码** | 拆分域名、路径、Query、Hash；参数表格编辑；URL/Component 编解码 | 排查链接、回调地址和接口参数 | 小～中 |
| **文本批处理** | 行去重、排序、去空行、首尾去空白、添加前后缀、分隔符转换 | 处理日志、ID 列表和批量数据，补齐现有文本工具 | 小 |
| **JWT 查看器** | 展示 Header/Payload，解释常见字段，将 `exp/iat/nbf` 转为可读时间 | 登录与鉴权排查；明确区分内容解析和签名验证 | 小 |
| **Cron 调试器** | 字段解释、常见模板、指定时区、预览未来 10 次执行时间 | 快速核对定时任务；需明确支持的 Cron 方言 | 中 |
| **SQL 格式化** | MySQL/PostgreSQL 方言选择、缩进、关键字大小写、压缩 | 整理日志 SQL 和复杂查询；仅处理文本 | 中 |
| **JSON 增强** | JSONPath 查询、字段路径复制、键排序、结构差异比较 | 延伸已有核心工具，尤其适合分析大型接口响应 | 中～大 |

其中，**URL 工具和文本批处理投入较小、适用面广；JWT 和 Cron 能明显扩展使用场景；JSON 增强最适合持续打磨。**

## 整体体验候选

- **收藏与固定排序：** 当前已有最近工具记录，可增加用户主动收藏，方便工具数量增长后的导航。
- **跨工具传递结果：** 例如 Base64 解码后送入 JSON，JSON 输出送入 Diff，减少复制粘贴。
- **偏好设置：** 增加全局唤醒快捷键自定义、默认工具、编辑器字号与缩进；当前设置页仅有主题。
- **可选草稿恢复：** 现有缓存支持同次运行内切换页面；可进一步支持重启恢复，由用户主动开启，密钥、密码、Token 默认不落盘。

## 规划边界与后续验证

继续保持本地处理和离线可用。HTTP 客户端、云同步、AI 助手、插件市场暂列远期方向，它们会显著扩大产品和维护范围。

初始候选规划不涉及功能代码或接口修改；二维码生成与 PNG 导出已进入实现批次，验证范围见上文。其余功能选定后再细化实现和验收；重点覆盖中文与 emoji、非法输入、大整数精度、时区边界，以及大输入下的界面响应。
